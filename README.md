One funny line pitching the worst pizza topping ever invented, written by
`main.py` to `/output/entry.txt` for the
[make.fun bounty](https://make.fun/bounty/u-motasimfuad-the-worst-pizza-topping-062c6893).

## The line

> Try our new pizza topping: the chef's resignation letter, shredded over
> mozzarella — bitter, tangy, and the last thing he'll ever cook here.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program writes exactly one line of UTF-8 text, 1–200 characters, and
checks before writing that the line mentions both a pizza and a topping.
It is deterministic: every run writes the same bytes.
